# 行知页面设计规范

本轮以 [ai-design-skills / landing-page-design](https://github.com/elayadesign/ai-design-skills/tree/main/skills/landing-page-design) 为主要规范，使用同作者的 [redesign-existing-projects](https://github.com/elayadesign/redesign-skill) 辅助审阅已有界面。技能安装在当前 Codex 用户的技能目录中，没有覆盖项目 AGENTS.md。

## 设计目标

面向旅行者与活动组织者，让首次访问者理解行知能提供什么，并进入对话规划。介绍页采用双栏首屏和明确标注的行程结构示例，接续规划收益、三步使用流程、品牌文案、六项常见问题与相同的主要行动入口。示例不是实时行程，不使用虚构客户评价或使用量。

保留绿色品牌和既有山水图片，介绍页用独立 CSS Modules 管理，避免与工作区、导出文档混用样式。登录与工作区在原样式文件内更新，保留账户、地图、对话、票价和规划逻辑。

## 主要设计值

- 字体：既有本地 Geist；中文由系统中文字体补齐字形。新增页面不引入第二套展示字体，不使用斜体或超粗字重。
- 主色：`#245c43`；浅色底：`#f7f8f2`；辅助面：`#eaf0e1`。背景使用纯色，渐变仅用于介绍页主标题文字。
- 正文与标题采用 Tailwind 默认字号阶梯：12、14、16、18、20、24、30、36、48、60、72px，配套对应行高。
- 新增间距遵循技能的封闭标尺：0、2、4、8、12、16、24、32、40、48、64、80、96px。
- 主要面板圆角16px，内嵌控件8px；图标沿用 Phosphor。
- 动效使用 `cubic-bezier(.22,1,.36,1)`，仅改变位移和透明度；滚动进入使用 IntersectionObserver；减少动态效果时直接展示内容。

## 实现与辅助体验

- 手机介绍页导航为全屏面板，支持 Escape、焦点循环和关闭后返回触发按钮。
- 工作区导航在手机端覆盖完整视口；提示和消息字号提升，保留键盘焦点样式。
- 登录请求进行时显示明确的会话建立状态，接口错误仍在表单内展示。
- 补充键盘跳转主要内容、数据说明、使用说明、品牌404和社交分享元数据。
- Turbopack 的 Tailwind 全局 CSS loader 排除 `.module.css`，让 Next 原生处理模块样式及类名，防止模块导出失效。

## 验收范围

使用真实 Chromium 检查介绍页、登录页和工作区的桌面与手机布局。工作区使用本地接口夹具，避免写入线上账户；这些检查不代表后端、模型或航司服务的重新验收。现有116项测试、目标文件 ESLint、TypeScript和生产构建用于回归检查。

2026-10-31已随 `20261031-workspace-design` 发布线上。六个工作区加入统一标题、任务入口、真实记录统计与空状态。执行表单、收藏核对和版本保存使用本地夹具检查；线上使用真实账户检查页面访问及模型工具调用。预发布与正式环境各17项检查通过，原前端及配置保留备份。
