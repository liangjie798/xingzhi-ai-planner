# 多轮对话验收（2026-10-27）

对话处理优先识别礼貌回复、模型验证、无效输入和绘图意图，再进入交通、天气、知识与活动规划。礼貌回复和绘图请求不覆盖活动条件。模型验证通过真实 completion 请求取得回答，展示接口返回的模型标识、调用耗时和本次请求编号；未配置或失败时明确说明没有取得模型回答。账户已有的模型配置会在登录后恢复，登录本身不提供模型额度。评委账户暂不创建。

活动评分解释直接使用当前方案保存的完整活动窗口和条件，按后端 RiskCalculator 的扣分规则展示热风险、空气质量、降雨、人群、活动类型和时长贡献。没有指定开始时间时，明确比较每个日期在指定时段中评分最高的完整窗口；无对应窗口时不推测分差。历史数据与当前公式不一致时提示重新分析。

天气对比图独立保存城市、日期和指标。修改图表会重新查询对应城市、日期的逐小时数据，不修改活动方案。缺失日期保留为空并标记，不能用其他日期替代。逐小时页面增加全国城市、区县搜索，并在切换城市时取消上一请求，防止旧数据覆盖新城市。

无效条件在清洗和合并之前拦截。1.5小时识别为90分钟，明确告知当前排程只支持1至8个整小时；2月30日、0人等输入停止本次计算。旧方案可供查看，不被当作已完成修改。

## 验证结果

- 前端84项测试、ESLint、Next生产构建通过。
- 线上接口验证：礼貌回复保留交通条件、目的地修改、火车筛选不改目的地、非法输入停止、天气转绘图、图表城市和日期独立修改、未配置模型如实失败。
- 真实浏览器：杭州运动会，300名初中生，中强度，2小时，10月28日至29日，仅下午。10个有效候选全部在12:00–18:00内。两日下午最佳窗口分别63分、46分，解释中的17分差及扣分项与保存结果一致。
- 将图表切换为北京，再改为10月30日与11月1日，取得对应48个小时数据，杭州活动条件及评分保持不变。
- 新对话查询西安明天天气，随后绘制明天与后天气温对比，取得48个小时数据，未生成虚构活动条件。
- 逐小时页面搜索南宫市，取得24小时数据；390px移动端无横向溢出。

模型成功和402失败的传输行为使用隔离的HTTP响应测试验证。线上服务器默认模型密钥为空，实际验证了失败提示；尚未完成带有效账户模型密钥的线上成功调用，不能据此宣称默认大模型已经可用。天气与评分数据均为验收时快照，会随更新变化。
