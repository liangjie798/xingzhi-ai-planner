# 自动票价查询

用户只需提供出发城市、到达城市和日期，例如“明天西安到榆林怎么走便宜”。旧版手动票价、时间价值和附加费表单已撤下。交通日期单独保存，不覆盖目的地活动排程。

## 授权配置

1. 登录 https://cmcp.variflight.com/，完成平台授权并生成 MCP Key。账户需具备对应工具的权限与额度。
2. 本地填入 `frontend/.env.local` 的 `VARIFLIGHT_MCP_KEY`。生产环境在 `/etc/shihou/frontend.env` 填入同名变量，重启 `shihou-frontend`。密钥不使用 `NEXT_PUBLIC_`，不要提交 Git 或发送到聊天。
3. 通过界面查询实际线路，检查来源、日期、价格、可售席位及查询时间。未设置密钥时会显示尚未启用，不能视为真实数据验收通过。

固定 MCP 地址：`https://c-gw.variflight.com/chat_message/mcp/api`。使用 Streamable HTTP 初始化、会话头、JSON/SSE 响应及嵌入 JSON 资源。通过 `tools/list` 核对机票工具名称与 SQL 入参；仅允许查询城市、实时票价及火车详情，不会订票、支付、读取个人行程或创建监控。当前实际服务将 SQL 机票工具命名为 `getFlightTicketPrice`，文档中的 `getRouteFlightTickets` 作为兼容名称保留；非 SQL 价格日历工具不会用于实时比较。

## 查询与边界

- 城市代码来自 `searchAirport` 的明确城市匹配，歧义不猜测；航班使用文档给出的只读 SQL，固定参数，不执行用户或模型生成的 SQL。
- 航班比较成人经济舱含税 `adult_total`、直飞非共享候选，最多3项。保留真实 `option_id`，不能将方案编号说成航班号。
- 火车从城市直达查询返回的真实车次和站点代码获取详情，按低价及较短时长挑选最多6个候选。只接受有明确价格、席别和可售余票的数据；详情 `seatPrice` 单位为分，必须除以100。每个候选只展示最低可售席位，同价优先有座；明确展示出发车站，市域其他站点的接驳费未计入比较。
- 丢失授权、超时、字段无法识别、尚未开售都显示无法取得报价。缺失金额不是0元；搜索新闻、历史报价不参与计算。
- 不承诺全网最低价，不计算接驳、额外行李或学生优惠。只取得一种方式时，不判断它比另一种便宜。相同线路与日期的成功结果在服务内存复用最多60秒，显示原始查询时间；最多60组，不持久化为实时数据。改变日期/城市后不显示其他条件的结果。
- 已使用有效授权核对城市集合、火车直达检索、火车详情的分单位以及 SQL 机票 JSON 资源的真实返回结构。服务端字段缺失或无法识别时仍保持不可用，不猜测票价。授权成功不代表免费，具体调用费用及额度以相应账户为准；不自动充值或购买套餐。

官方文档：https://cmcp.variflight.com/tools/
