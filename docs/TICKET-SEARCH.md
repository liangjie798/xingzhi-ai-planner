# 自动票价查询

用户只需提供出发城市、到达城市和日期，例如“明天西安到榆林怎么走便宜”。旧版手动票价、时间价值和附加费表单已撤下。交通日期单独保存，不覆盖目的地活动排程。

## 授权配置

1. 登录 https://cmcp.variflight.com/，完成平台授权并生成 MCP Key。账户需具备对应工具的权限与额度。
2. 本地填入 `frontend/.env.local` 的 `VARIFLIGHT_MCP_KEY`。生产环境在 `/etc/shihou/frontend.env` 填入同名变量，重启 `shihou-frontend`。密钥不使用 `NEXT_PUBLIC_`，不要提交 Git 或发送到聊天。
3. 通过界面查询实际线路，检查来源、日期、价格、可售席位及查询时间。未设置密钥时会显示尚未启用，不能视为真实数据验收通过。

固定 MCP 地址：`https://c-gw.variflight.com/chat_message/mcp/api`。使用 Streamable HTTP 初始化、会话头、JSON/SSE 响应及嵌入 JSON 资源。只允许 `searchAirport`、`getRouteFlightTickets`、`domesticDirectTrainSearch`、`trainDetail`，不会订票、支付、读取个人行程或创建监控。

## 查询与边界

- 城市代码来自 `searchAirport` 的明确城市匹配，歧义不猜测；航班使用文档给出的只读 SQL，固定参数，不执行用户或模型生成的 SQL。
- 航班比较成人经济舱含税 `adult_total`、直飞非共享候选，最多3项。保留真实 `option_id`，不能将方案编号说成航班号。
- 火车从城市直达查询返回的真实车次和站点代码获取详情，最多6个候选。只接受有明确价格、席别和可售余票的数据；缺失、售罄或候补不能作为最低价。
- 丢失授权、超时、字段无法识别、尚未开售都显示无法取得报价。缺失金额不是0元；搜索新闻、历史报价不参与计算。
- 不承诺全网最低价，不计算接驳、额外行李或学生优惠。只取得一种方式时，不判断它比另一种便宜。报价不持久化为实时数据，改变日期/城市后不显示旧结果。
- 当前适配器依据公开入参文档编写。公开文档未完整列出返回结构；配置有效授权后，必须用真实返回验证字段映射，未识别时保持不可用，不猜测票价。

官方文档：https://cmcp.variflight.com/tools/
