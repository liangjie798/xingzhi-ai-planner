# 行知界面更新

## 审阅与方向

本次依据 design-taste-frontend 的改版、可读性和无障碍规则。产品主要面向旅行者与活动组织者，工作台优先保证对话、真实数据、方案编辑的使用效率；介绍页承担品牌表达。

原界面主要问题：六个横向导航和历史对话栏争夺首屏空间；对话与条件面板挤压；正文、来源和表单字号层级不统一；介绍页使用模拟对话卡片，缺少完整的品牌视觉。

采用浅色旅行工作台，保留森林绿、指南针标识、行知名称、六个导航标签及现有路由。设计参数：DESIGN_VARIANCE=6，MOTION_INTENSITY=3，VISUAL_DENSITY=4。继续使用现有 Radix 与 Phosphor，不增加组件库。

## 变化

- 桌面左侧统一导航、历史对话、新建和删除；移动端用支持键盘与焦点管理的 Radix Dialog。
- 缩小工作区顶部占用，开始交流后收起欢迎标题；聊天正文 14–15px，保持每条消息完整高度。
- 统一森林绿、白色表面、灰绿色边框、14px 面板圆角，完善焦点和减弱动效设置。
- 登录与访客共享一致的表单位置和字号；介绍页使用山谷与行前笔记两张品牌意境图。这两张图片由 ImageGen 生成，不用于地点推荐或地点证据。
- 地图、图表、方案、执行管理与资料收藏使用同一视觉层级；计算逻辑、条件、会话隔离、票价接口和导出格式沿用现有实现。
- 品牌图片提前编码为 WebP，直接静态加载，避免低内存服务器在请求中执行原生图片处理。

## 验证范围

2026-10-27 验证：

- ESLint、TypeScript 和生产构建通过，现有 78 项前端行为测试通过。
- 本地 1600/1440px 桌面与 1024/768/390px 布局检查，无横向溢出；初始输入框位于首屏。登录用户/访客切换前后，身份选项卡坐标一致。
- 手机导航支持打开、跳转后关闭与 Escape 关闭。桌面历史记录、新建对话和移动端历史列表可用。
- 线上全国地图取得 34/34 个地区采样并正常着色。高德产生一条 Canvas 性能建议，未影响地图交互。
- 线上实际分析“杭州、明天、体育课、40名初中生、两小时、中强度、14:00–16:00”，保存的条件、评分图和规划书一致；另建西安天气对话后切回，原分析与方案完整恢复，未混入西安上下文。390px 方案无横向溢出。
