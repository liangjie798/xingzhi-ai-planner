# 多轮对话、重算与管理平台

用户说“西安明天天气”，随后说“大后天呢”“一周后呢”时，结构化天气上下文保存城市和日期；时间按北京时间的今天解析。超出今天至第六天的可用范围直接说明限制，不再对省略问题进行泛搜索。

已有活动方案时，“改成一小时”“参与者改为老人”“只看下午”优先解释为修改，保留其他已确认条件。下午约束为 12:00–18:00，整段活动都必须在该范围内；用户可以说“不限时段”解除约束。“画两天的对比图”从当前日期重新查询两天并重新评分，用真实结果绘制按日期分组的柱状图。

评分对每个候选开始时间遍历完整活动时长。同一天缺少任一小时则不推荐该窗口。气温取均值，US AQI、热风险和降水概率取窗口最大值，并叠加人群、强度、场景与暴露时长因子。图表、最优时间和规划文档共享本轮结果。旅游候选地点同样按人群和低步行需求筛选，模型超出用户时间范围则使用受约束的规则方案。

`GET/PUT/DELETE /api/v1/conversation-memory` 仅处理当前会话身份：注册用户按账号保存，重新登录可恢复；访客和未登录用户在 HttpSession 保存。保存最近 60 条消息、确认条件、天气/目的地上下文及最新分析结果，不保存模型密钥。可在对话栏清除记忆。记忆不是自动训练知识库，旧预报恢复后仍应按新日期重新查询。

`/admin` 提供用户列表检索、新增、显示名/状态修改、密码重置及删除。新增只能创建 USER；管理员和超级管理员不能在普通用户管理中更改或删除。删除用户及其关联个人记录不可撤销，页面二次确认；所有写操作需要管理员角色和 CSRF。停用和删除后，原会话后续 API 请求返回 401。

用户在分析台“问题反馈与处理进度”填写标题和说明，提交到 `POST /api/v1/feedback`，不会自动附带私有对话。管理员在反馈收件箱查看、回复、更新待处理/处理中/已处理状态或删除。`GET /api/v1/feedback` 只返回当前提交者的记录与回复；不能通过传递用户 ID 查看他人的反馈。

验证包含：连续天气日期、条件修改保留、多日评分、完整窗口、时段硬约束、账户记忆隔离、用户 CRUD 权限、超级管理员保护、停用会话失效和反馈回复闭环。
